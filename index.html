PROJECT / 01

Mobil Robot Arduino

Saya pernah membuat robotik mobil kecil yang digerakkan menggunakan coding melalui aplikasi di HP. Arduino Uno digunakan sebagai inti pengendali, sehingga mobil dapat menerima instruksi dan bergerak sesuai program.

Arduino UnoCodingKontrol HP

Projek ini menjadi pengalaman awal saya saat menduduki bangku SD dalam menggabungkan perangkat keras dan pemrograman. Saya belajar mengenal komponen, menyusun rangkaian, serta memahami bagaimana instruksi dari aplikasi dapat mengendalikan gerak mobil robot.
